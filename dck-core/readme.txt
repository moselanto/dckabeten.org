=== DCK Core ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Core features for Deliverance Church Kabete N Market, designed for the DCK Elite Pro theme.

* DCK Church > Church Settings: one screen for all site content (contact, service times, homepage, ministries, giving, live stream, SEO, terms and privacy). Quick search, image picker, add/remove/reorder lists.
* Sermons content type owned by the plugin, so sermons survive a theme change.
* Uses the same storage as the Customizer, so nothing needs migrating and both stay in sync.

Install: upload the dck-core folder to wp-content/plugins and activate.
